## Практическое занятие №9

Созданы отдельный проект, index.html, css/custom.css, README и .gitignore. Bootstrap CSS и JS Bundle подключены через CDN. Hero использует две колонки col-12 col-lg-6; преимущества — col-12 col-md-4; товары — col-12 col-md-6 col-lg-4 с g-4. Шапка, navbar и подвал выполнены на Bootstrap. Начальные ссылки на будущие страницы временно ведут к секции коллекции; полноценные страницы добавлены следующим этапом.

## Практическое занятие №10

Добавлены страницы каталога, товара и заявки, одинаковая navbar, активный пункт меню, card/btn/badge/alert, Bootstrap Modal и поля формы, Accordion, характеристики и изображения. Связи data-bs-target, aria-controls и ID уникальны на каждой странице. Небольшие улучшения сценария заказа и фильтрация выделены в js/main.js.

## Практическое занятие №11

Выполнена итоговая проверка и дополнительное локальное подключение Bootstrap без CDN. Подготовлены критерии, проверки, описание и защита. Итог публикуется через GitHub Pages. Задание по КР №3 из документа №11 только ставится преподавателем; реализация КР №3 не является частью сдачи КР №2.
