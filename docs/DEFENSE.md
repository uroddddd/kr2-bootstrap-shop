## Основные классы

- container ограничивает ширину и центрирует содержимое; container-fluid занимает доступную ширину.
- row — строка сетки. col-* находится внутри row. Всего 12 колонок.
- col-12 — вся ширина; col-md-6 — половина от 768px; col-lg-4 — треть от 992px. Подход mobile-first.
- g-4 — промежутки между колонками и строками; p-4 — внутренний отступ; my-5 — внешний вертикальный; mb-3 — нижний.
- card — карточка; btn-primary — основная кнопка; btn-outline-primary — контурная; badge — метка; alert — сообщение.
- form-control — текстовое поле/textarea; form-select — select; input-group — поле с префиксом +7; form-check — чекбокс.
- modal-dialog/modal-content/modal-header/modal-body разделяют окно. modal-dialog-scrollable даёт прокрутку; data-bs-dismiss закрывает.
- aria-current="page" сообщает текущую страницу; aria-controls связывает кнопку с панелью; label for совпадает с id поля.

## Что происходит по нажатию «Заявка»

1. Bootstrap по data-bs-* находит Modal и генерирует show.bs.modal.
2. Наш обработчик читает data-product у нажатой кнопки и выбирает этот товар в select.
3. Bootstrap показывает окно и удерживает клавиатурный фокус внутри него.
4. При отправке браузер проверяет required, email и pattern телефона.
5. Наш submit отменяет отправку, показывает точное сообщение об учебной проверке, очищает форму и закрывает Modal.

Сервера, базы данных и оплаты нет. «Проверить заявку» не отправляет настоящий заказ. Телефон после отдельного префикса +7 вводится как 900 123-45-67.

## Самостоятельные доработки

Локальный Bootstrap, пять дополнительных страниц, работающие фильтры, подстановка товара в обе формы, размер и получение, Tabs и Accordion, изображения и варианты карточек, адаптивные таблицы и документация. Нужно уметь показать код каждого добавления, а не только перечислить его.
