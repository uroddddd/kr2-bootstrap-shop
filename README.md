## Описание

Отдельная реализация магазина одежды на **Bootstrap 5.3.8** по практическим занятиям №9–11. КР №1 хранится в другом репозитории: `kr1-html-css-shop`. Общей осталась предметная область; разметка, сетка, формы и интерактивные компоненты КР №2 построены заново на Bootstrap. Студийные предметные изображения созданы для учебной коллекции.md.

HTML создаёт страницы, Bootstrap задаёт сетку и готовые компоненты, `css/custom.css` содержит только небольшие правки цветов, изображений и фокуса. JavaScript проекта добавляет подстановку товара, проверку учебной заявки и фильтрацию трёх карточек. React, Vue, Sass, npm и сборка не используются.

## Bootstrap: CDN и локальное подключение

В ветках занятий №9 и №10 Bootstrap подключён через CDN jsDelivr. В итоговой ветке выполнено дополнительное задание №11: **полностью локальное подключение**, без резервного CDN и внешних шрифтов.

```html
<link rel="stylesheet" href="vendor/bootstrap/css/bootstrap.min.css">
<link rel="stylesheet" href="css/custom.css">
<!-- Перед закрывающим body: -->
<script src="vendor/bootstrap/js/bootstrap.bundle.min.js"></script>
<script src="js/main.js"></script>
```

Compiled CSS и JS Bundle версии 5.3.8 скачаны из официального пакета `bootstrap` на jsDelivr. Bundle включает Popper. Лицензия MIT сохранена в `vendor/bootstrap/LICENSE`; минифицированные файлы библиотеки не редактировались. `custom.css` подключён после Bootstrap, а наш скрипт — после Bundle.

Официальные материалы: [загрузка](https://getbootstrap.com/docs/5.3/getting-started/download/), [сетка](https://getbootstrap.com/docs/5.3/layout/grid/), [Modal](https://getbootstrap.com/docs/5.3/components/modal/), [формы](https://getbootstrap.com/docs/5.3/forms/overview/).

## Сетка и компоненты

- `container` ограничивает содержимое; `container-fluid` используется для широких фоновых полос.
- `row` и `col-12 col-md-6 col-lg-4` дают одну, две и три колонки карточек.
- `g-*`, `my-*`, `mb-*`, `p-*`, `d-flex`, `gap-*`, `h-100` задают отступы, выравнивание и высоту.
- `navbar` + `collapse`: единое меню с кнопкой на небольших экранах.
- `card`, `btn` разных вариантов, `badge`, `alert`: карточки, действия, метки и сообщения.
- `form-control`, `form-select`, `input-group`, `form-check`: поля, список, префикс телефона и согласие.
- `modal`: быстрая заявка с прокруткой и закрытием через Escape, крестик, кнопку и фон.
- `accordion`: FAQ; `nav-tabs` + `tab-pane`: характеристики и уход.
- `breadcrumb`, `table`, `table-responsive`, `list-group`: дополнительная навигация и справочные данные.

Bootstrap сам обрабатывает компоненты через `data-bs-toggle`, `data-bs-target`, `data-bs-dismiss`. Собственный код не переписывает механику Modal, Collapse, Accordion или Tabs.

## Дополнения сверх базовой инструкции

1. Локальный Bootstrap: сайт не зависит от доступности CDN после скачивания проекта.
2. Пять дополнительных страниц: две отдельные модели, контакты, доставка, размеры и уход.
3. Фильтры категории и максимальной цены с количеством результатов, сбросом и состоянием «ничего не найдено».
4. Карточки с изображениями, тремя вариантами badge и крупными фотографиями. «Подробнее» ведёт на соответствующий товар.
5. Выбранный товар передаётся в Modal и на `order.html?product=...`. В форме есть размер и способ получения; ссылки помогают сравнить размеры до заявки.
6. Дополнительные Bootstrap-компоненты Accordion, Tabs, Breadcrumb, адаптивные таблицы и List group.
7. Единый монохромный стиль, доступные названия, видимый фокус, подписи полей и статус результата. На 390/768/1366 px содержимое проверено на переполнение.

## Запуск

Откройте папку целиком в VS Code и `index.html` в браузере. Итоговая версия использует локальные CSS, JS и картинки, внешние запросы для работы не нужны. Для удобной проверки можно из папки проекта выполнить:

```sh
python3 -m http.server 8000
```

Затем откройте `http://localhost:8000`. Устанавливать зависимости не нужно.

## Работа формы и ограничения

Это учебная витрина: сервер, база данных, оплата, отправка почты и реальные заказы отсутствуют. Ничего не записывается в localStorage или cookie. Контакты и условия доставки вымышлены.

Обязательны имя (от двух символов), email, телефон, товар/тема и согласие. Телефон вводится без повторения префикса +7: `900 123-45-67`. Размер, получение и комментарий доступны в обеих формах. Используется нативная HTML-валидация (`required`, `type`, `pattern`) и `reportValidity()`. Обработчик `submit` отменяет отправку через `preventDefault()`, показывает точное сообщение о клиентской проверке, очищает форму и закрывает Modal. При отключённом JavaScript интерактивные компоненты не работают; noscript сообщает об ограничении.

Для теста: `Тест`, `student@example.com`, `900 123-45-67`, любой товар и согласие. Параметр товара из URL принимается только из заранее заданного списка.
